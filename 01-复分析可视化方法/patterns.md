# 模式与框架库

## 框架：把几何命题翻译成复等式

教材全书的固定套路，遇到"垂直且等长""共线""三点共圆"这类话，按四步走：

1. **选原点，把关键点写成复数。** 通常选一个顶点或图形的中心，让尽量多的点坐标变简单。
2. **把边或位移写成复数。** 每条带方向的边就是一个复数，长度是模，方向是辐角。
3. **把结论翻译成一个方程。** "垂直" = 乘以 $i$；"等长" = 模相等；两者合起来 = $B=iA$ 或 $A+iB=0$。
4. **用已知条件（通常是封口条件 $\sum=0$）算完。**

判断标准：如果算到最后所有项自动抵消，说明翻译对了；如果剩下一个解不掉的式子，多半是第 1 步的原点选错了。

## 决策规则

- **要算长度、角度、乘除** → 换极坐标 $r\angle\theta$ 或 $re^{i\theta}$。
- **要算加法、平移** → 用笛卡儿坐标 $x+iy$。
- **看到"转 $90°$"** → 直接乘 $i$，别写旋转矩阵。
- **看到"两个旋转复合"** → 写成 $e^{i\theta}z+v$ 的形式，角度直接相加；若总角度是 $2\pi$ 整数倍，结果是平移。
- **看到 $x^n-1$、$x^n+1$ 的因式分解** → 先画单位根，共轭配对。
- **看到点乘叉乘** → 写成 $\bar ab$，实部虚部各取所需。

## 反模式

- **把复数当两个实数分开处理。** 一旦拆成 $a$ 和 $b$ 分别算，乘法法则就变成一堆看不出意义的交叉项。教材反复强调"复数是不可分的整体"。
- **用三角恒等式去证复数的几何性质。** 教材 p.8 脚注直接点名批评这种做法：那些恒等式本身只是乘法法则的复杂化表现。
- **把 $e^{i\theta}=\cos\theta+i\sin\theta$ 当成定义。** 这样等于放弃解释，后面遇到 $e^z$ 的映射性质就接不上。
- **忽略辐角的多值性。** 在需要判断"绕了几圈"的时候（第 7 章），直接把 $\arg$ 当单值函数会得出错误结论。
- **把叉乘当成三维专属。** 平面上它是有符号面积，本书的积分公式全靠这个符号。
