# 速查表

## 第 1 章：几何和复算术

| 场景 | 内容 |
|---|---|
| 模与共轭 | $\|z\|=\sqrt{a^2+b^2}$，$\bar z=a-ib$，$z\bar z=\|z\|^2$ |
| 实部虚部 | $\operatorname{Re}z=\frac{z+\bar z}{2}$，$\operatorname{Im}z=\frac{z-\bar z}{2i}$ |
| 极坐标 | $z=r\angle\theta=re^{i\theta}$，$\theta$ 可差 $2k\pi$ |
| 加法 | $(a+ib)+(c+id)=(a+c)+i(b+d)$，平行四边形法则 |
| 乘法（几何） | 长度相乘，角度相加 |
| 乘法（代数） | $(a+ib)(c+id)=(ac-bd)+i(ad+bc)$ |
| 除以复数 | $\frac{1}{z}=\frac{\bar z}{\|z\|^2}$，$\frac{z_1}{z_2}=\frac{z_1\bar z_2}{\|z_2\|^2}$ |
| 乘以 $A$ 的几何意义 | 绕原点转 $\arg A$，放大 $\|A\|$ 倍 |
| 欧拉公式 | $e^{i\theta}=\cos\theta+i\sin\theta$，$\|e^{i\theta}\|=1$ |
| 三角反解 | $\cos\theta=\frac{e^{i\theta}+e^{-i\theta}}{2}$，$\sin\theta=\frac{e^{i\theta}-e^{-i\theta}}{2i}$ |
| 倍角 | $\cos4\theta$ 类问题：把 $2\cos\theta=e^{i\theta}+e^{-i\theta}$ 展开配对 |
| 单位根 | $z^n=1$ 的根 $e^{ik2\pi/n}$，$k=0,\dots,n-1$ |
| 因式分解 | $z^n-1=\prod_{k}(z-e^{ik2\pi/n})$；共轭配对得 $z^2-2z\cos\frac{2k\pi}{n}+1$ |
| 点乘叉乘 | $\bar ab=\mathbf a\cdot\mathbf b+i(\mathbf a\times\mathbf b)$ |
| 多边形面积 | $A=\frac12\operatorname{Im}(\bar ab+\bar bc+\cdots)$，顶点逆时针 |
| 保向运动 | $M(z)=e^{i\theta}z+v$；反射复合两次 = 旋转 $2\varphi$ |
