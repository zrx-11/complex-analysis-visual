# 深度推导：指数为什么是整数、为什么不能消掉

前置清单：

1. **向量场**：$V(z)=P+iQ$，每点给一个非零箭头（除奇点外）。
2. **辐角**：$\arg V$ 是箭头方向，可以加减 $2\pi$。
3. **环绕数**：闭曲线绕点的圈数，整数、连续变形不变。
4. **奇点隔离**：在奇点周围取小圆，圆上 $V\ne0$。

## 第 0 步：要证什么

1. 指数 $\frac{1}{2\pi}\Delta_\Gamma\arg V$ 是整数。
2. 连续变形不扫过奇点时，指数不变。
3. 指数不为零的奇点不能靠局部连续变形消掉。

## 第 1 步：整数性

绕奇点一圈，$V(z)$ 回到起点的值（同一点，同一个箭头）。所以 $\arg V$ 的连续变化只能差 $2\pi k$：

$$\Delta_\Gamma\arg V=2\pi k.$$

除以 $2\pi$ 得整数。这一步与环绕数完全同构：把"$V$ 的箭头"看成一条曲线，指数就是这条曲线绕 0 的环绕数。

## 第 2 步：变形不变

设 $V_s$ 是一族向量场，$s\in[0,1]$，奇点固定，$s$ 变化时不扫过奇点。对每个 $s$，指数是整数。而 $\arg V_s$ 关于 $s$ 连续（$V_s$ 在圆上不为零），所以指数关于 $s$ 连续。整数 + 连续 ⇒ 常数。

## 第 3 步：为什么不能消掉

假设奇点指数为 $k\ne0$。若能用局部连续变形把 $V$ 改成"没有奇点"的场，那么这个变形过程中指数必须从 $k$ 变到 0，但第 2 步说它不能变。矛盾。

所以指数是拓扑荷：$+1$ 的源不能连续变成无奇点，$-1$ 的鞍点也不能。

## 第 4 步：指数与留数的关系

若 $\bar V$ 在奇点附近解析（除奇点外），则

$$\frac{1}{2\pi i}\oint\frac{\bar V'}{\bar V}dz=\text{指数}.$$

这是辐角原理用在 $\bar V$ 上。第 11 章会把它与留数连接：$\bar V$ 的零点阶数就是指数。

## 数值算例一：$V=z^2$

$V=e^{2i\theta}$，绕一圈 $\Delta\arg=4\pi$，指数 $+2$。这是"二阶零点"，箭头转两圈。

## 数值算例二：$V=1/z$

$V=e^{-i\theta}/r$，$\Delta\arg=-2\pi$，指数 $-1$。这是"极点"，箭头反向转一圈。

## 反例：指数为 0 的奇点

$V(z)=z\bar z$ 在 0 处为零，但 $V=r^2$ 是实正数，方向恒为 0（或说 $\arg=0$），绕一圈 $\Delta\arg=0$，指数 0。这种奇点可以靠局部变形消掉（把 $r^2$ 改成 $r^2+\epsilon$），不具拓扑保护。
