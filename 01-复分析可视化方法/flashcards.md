# 《复分析：可视化方法》抽认卡

## 第 1 章

### 卡片：复数乘法的两条几何规则是什么？
- **背面**：长度相乘，角度相加。
- **标签**：乘法, 基础
- **章节**：ch01

### 卡片：乘以 A=R∠φ 对整个平面做了什么？
- **背面**：绕原点转 φ，再把每点到原点的距离放大 R 倍。
- **标签**：乘法, 变换
- **章节**：ch01

### 卡片：为什么 i²=-1？
- **背面**：i 是转 90°，i² 是转两次 90° 共 180°，落点就是 -1。
- **标签**：乘法, i
- **章节**：ch01

### 卡片：e^(iθ) 在复平面上是哪一点？
- **背面**：单位圆上辐角为 θ 的点，坐标是 (cosθ, sinθ)。
- **标签**：欧拉公式
- **章节**：ch01

### 卡片：用动点论证欧拉公式，关键一句话是什么？
- **背面**：d/dt e^(it) = i e^(it)，速度永远垂直于位置，所以只能贴单位圆走。
- **标签**：欧拉公式, 证明
- **章节**：ch01

### 卡片：cosθ 用指数怎么表示？
- **背面**：cosθ = (e^(iθ) + e^(-iθ)) / 2。
- **标签**：欧拉公式, 公式
- **章节**：ch01

### 卡片：zⁿ=1 的根有几个，位置在哪？
- **背面**：n 个，均匀分布在单位圆上，构成内接正 n 边形的顶点。
- **标签**：单位根
- **章节**：ch01

### 卡片：ā b 的实部和虚部分别是什么运算？
- **背面**：实部是点乘，虚部是有符号的叉乘（面积）。
- **标签**：向量, 乘法
- **章节**：ch01

### 卡片：多边形面积公式（顶点逆时针 a,b,c,d）？
- **背面**：A = ½ Im(ā b + b̄ c + c̄ d + d̄ a)，原点在形外也成立。
- **标签**：面积, 公式
- **章节**：ch01

### 卡片：每个保向运动的复数形式是什么？
- **背面**：M(z) = e^(iθ) z + v，即旋转加平移。
- **标签**：变换, 群
- **章节**：ch01

## 第 2 章

### 卡片：z^n 对长度和角度各做了什么？
- **背面**：长度升到 n 次方，角度乘以 n。
- **标签**：映射, 幂
- **章节**：ch02

### 卡片：z^n=c 的解在平面上怎么排？
- **背面**：半径 R^(1/n) 的圆上正 n 边形顶点，一个顶点角度为 φ/n。
- **标签**：映射, 单位根
- **章节**：ch02

### 卡片：幂级数的收敛域是什么形状？
- **背面**：以原点为心的圆盘；盘内绝对收敛，盘外发散，圆周逐点判断。
- **标签**：幂级数
- **章节**：ch02

### 卡片：收敛圆周上一定有什么？
- **背面**：至少一个奇点；否则半径还能扩大。
- **标签**：幂级数, 奇点
- **章节**：ch02

### 卡片：e^z 的两条核心几何事实？
- **背面**：周期 2πi；高度 2π 的水平带铺满 w 平面（去掉 0）。
- **标签**：指数, 映射
- **章节**：ch02

### 卡片：e^z 把虚轴映成什么？
- **背面**：单位圆；e^(iy)=cos y+i sin y，y 走多远就绕多少圈。
- **标签**：指数, 欧拉公式
- **章节**：ch02

### 卡片：多值函数的支点是什么？
- **背面**：z 绕它一圈回到原处时，函数值回不到原值的点。
- **标签**：多值, 支点
- **章节**：ch02

### 卡片：√[n]{z} 的支点在哪、阶数多少？
- **背面**：在 0，阶数 n-1；绕 n 圈才回到原值。
- **标签**：多值, 支点
- **章节**：ch02
